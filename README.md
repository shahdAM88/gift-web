# 🎁 Interactive Gift Website

A fun and interactive digital gift website built using HTML, CSS, and JavaScript.

The website takes the user through multiple interactive screens before revealing a collection of personalized gifts.

## ✨ Features

- Multi-step interactive experience
- Yes / No interaction
- Dynamic text changes
- Animated buttons and GIF reactions
- Interactive gift selection
- Three gift categories:
  - 🎵 Song
  - 💌 Letter
  - 📸 Photos

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🎯 About the Project

This project was created to practice front-end development and build a fun, customizable digital gifting experience.

The idea is to allow the website to be personalized with different messages, songs, photos, and styles for different people and occasions.
